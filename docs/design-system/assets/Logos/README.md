# Logos

The repo has no `icon.svg`; the PNG sizes ship in `public/icon/`. The mark is LeetSRS's, kept unchanged in this fork.

- `icon.svg` — the app icon: the NeetSRS mark stroked in `#6acb7b` on a `#141816` disc. It's for store listings, promo art and docs, not UI chrome. In UI, draw `NeetSRSLogo` (`shared/ui/NeetSRSLogo.tsx`) inline in `currentColor`, usually `brand`.
- `icon-128.png` — the raster icon at 128px (`public/icon/128.png`). The extension also ships 16, 32, 48, 60 and 96px versions.
- Both icon inks are fixed and are not tokens. The disc stays dark in both themes.
